# My Progress для macOS

Продовження наданого SwiftUI-застосунку: навчання, програмування, англійська, психологічний щоденник, спорт, задачі, денні цілі, статистика та досягнення. Основні функції працюють локально без облікового запису; AI-рефлексія необов’язкова.

Аналіз вихідної структури, проблем і прийнятих рішень: [docs/PROJECT_REVIEW.md](docs/PROJECT_REVIEW.md).

## Запуск на Mac

Потрібні **macOS 14+ і Xcode 16+** (Swift 6). Сторонніх пакетів немає.

```bash
cd says
swift test
swift run MyProgress
```

Для роботи через Finder створіть локальний `.app`:

```bash
./scripts/build-macos-app.sh
open .build/MyProgress.app
```

Або відкрийте `Package.swift` у Xcode й запустіть executable scheme `MyProgress`. Окремий `.xcodeproj` не потрібен. Якщо використовується лише Command Line Tools і Xcode уже встановлено, виберіть його toolchain через `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` для відповідних команд.

Пакет має Swift 5 language mode для сумісності з наданим SwiftUI-кодом, компілятор — Swift 6+. Локальний app bundle підписується ad-hoc; це не підписана й notarized дистрибуція. Зміна локального підпису після перебудови може спричинити повторний запит доступу до Keychain.

## Як користуватися

- **Огляд**: сьогоднішній і загальний час, серія активних днів, денні цілі, графік тижня й найближчі задачі.
- **Напрями**: одна ручна сесія на застосунок, вибір задачі, історія сесій, додавання завершеної активності вручну. Після зміни екрана трекінг триває.
- **Психологія**: вкладки щоденника та активності. Чернетка зберігається локально. Для AI-аналізу потрібні ключ у налаштуваннях і підтвердження перед надсиланням. Результат можна зберегти як окрему рефлексію.
- **Задачі**: категорії, терміни, редагування, виконання, фільтрація, сесія на конкретну задачу. Видалення задачі не видаляє історію часу.
- **Статистика**: 7/30/90 днів, фільтр напряму, хвилини за днями й розподіл часу.
- **Досягнення**: хвилина активності, 10 годин, перша/десята виконана задача, триденна серія, перша нотатка. Відкриття зберігаються.
- **Налаштування**: денні цілі, поріг бездіяльності, правила програм, Keychain, експорт/відновлення JSON.

Ручний режим має пріоритет над автоматичним. Зупинка ручної сесії повертає керування автоматичним правилам, якщо вони ввімкнені. Бездіяльність за заданим порогом і сон призупиняють облік; повернення активності відновлює ручний режим. Після нового запуску ручна сесія не відновлюється сама.

Автотрекінг **вимкнений за замовчуванням**. Є попередні правила Xcode та VS Code; додайте точний bundle ID своєї програми. Наприклад, `osascript -e 'id of app "Xcode"'`. Система використовує лише активну програму та час бездіяльності: без читання вікон, клавіш, екрана чи історії браузера. Браузерне правило враховує весь браузер, не лише навчальну вкладку. Спорт та заняття поза комп’ютером додаються вручну. Системні дані фокусу й бездіяльності можуть мати обмеження в окремих конфігураціях macOS; це треба перевірити на цільовому Mac.

## Збереження і старі дані

Основний файл: `~/Library/Application Support/MyProgress/progress-v1.json`. Запис атомарний, формат валідований і версіонований. Якщо файл не читається, зміни блокуються: виправте причину й натисніть «Повторити відкриття» або скористайтеся «Відновити з копії…» у повідомленні про помилку. Помилка не перезаписує файл порожнім документом.

За відсутності нового файлу переносяться оригінальні `*.totalTime` та `myprogress.journal.entries.v1` із поточного домену `UserDefaults`. Старі ключі не видаляються. Підсумки без дат включаються лише до загального часу. У початкових файлах немає bundle ID: якщо стара збірка зберігала дані під іншим ID, спочатку зробіть копію її preferences і перенесіть лише відповідні ключі до нового домену або використовуйте її bundle ID; не видаляйте новий JSON без резервної копії.

Експорт містить сесії, задачі, цілі, щоденник, правила й досягнення, але не ключ і не чернетку. Відновлення замінює поточний документ після перевірки та підтвердження, створюючи `backup-<UUID>.json` поруч із ним. Не запускайте кілька окремих процесів одночасно для одного файлу; вікна одного процесу використовують спільне сховище.

AI-ключ зберігається лише у macOS Keychain; старий спосіб `OPENAI_API_KEY` залишається резервним. Модель за замовчуванням — `gpt-4.1-mini`, override — `MYPROGRESS_AI_MODEL`. Доступ до моделі та API потребує власного ключа й квоти. Аналіз не є діагнозом.

## Перевірки

```bash
# Mac: ядро та компіляція macOS executable
swift test
swift build --product MyProgress

# Linux: лише незалежне ядро, потрібен Docker
./scripts/test-core-linux.sh
```

Linux не може збирати чи запускати SwiftUI/AppKit. Офіційний Swift Docker image закріплено за digest у Linux-скрипті. Тести перевіряють міграцію, збереження/валідацію, календарну статистику, нічні межі й літній час, паузи та великі розриви, перемикання задач, досягнення та форматування часу. Workflow `.github/workflows/macos.yml` перевіряє macOS build і збирає `.app` після push; він ще не виконувався у цьому середовищі.

На Mac додатково перевірте: запуск `.app`, збереження після перезапуску, старт задачі й перехід між екранами, автоматичне правило Xcode/VS Code, паузу під час бездіяльності та сну, експорт/відновлення, Keychain і необов’язковий AI-запит. Це ручні runtime-перевірки, не заміна `swift test`.
