# Аналіз наданого проєкту

Надано 12 Swift-файлів; GitHub-репозиторій спочатку порожній. Файлів Xcode, ресурсів, тестів, конфігурації підпису та відомостей про bundle identifier не було. Нижче «реалізовано» означає наявність відповідного коду, а не перевірений запуск початкового застосунку: macOS у поточному середовищі немає.

## Початкова структура

- `MyProgressApp` → `ContentView`: SwiftUI `WindowGroup`, навігація через `NavigationSplitView`.
- `ContentView` також містив `DashboardView` і `ProgressRow`.
- `ActivityView` → `ActivityTracker`: старт, стоп, скидання, форматування часу. Три напрями використовували цей екран.
- `ProgrammingView`, `EnglishView`, `SportView`, `PsychologyView`: окремі, майже однакові таймери; у головній навігації не використовувалися.
- `PsychologyJournalView` → `JournalStore` → `JournalEntry`: додавання, видалення, збереження нотаток у `UserDefaults`.
- `AIService`: запит до OpenAI Responses API, текстова рефлексія українською, обробка базових помилок; потребував ключа зі змінної середовища.

## Що вже було реалізовано

Інтерфейс напрямів, ручний секундний таймер, збереження сумарного часу, локальний психологічний щоденник, асинхронний AI-запит. Ці функції стали основою розвитку. Збережено головний SwiftUI entry point, підхід split-навігації, екран щоденника, Codable-поля його записів, промпт і механіку Responses API. Назви попередніх екранів залишено як сумісні entry points.

## Проблеми й відсутні компоненти

1. Окремі таймери на екранах могли працювати одночасно; навігація не управляла їхнім життєвим циклом.
2. Лише сумарний час: неможливо відновити дні, задачі або історію активності.
3. Dashboard читав `UserDefaults` напряму, тому не підписувався на оновлення трекера.
4. Запис у `UserDefaults` щосекунди; ручне скидання знищувало попередній підсумок без підтвердження.
5. Не було правил для сну, тривалих пауз, бездіяльності та завершення програми.
6. Немає задач, термінів, навчального напряму, щоденних цілей, досягнень чи статистики за період.
7. Помилки сховища повідомлялися лише через `print`; немає експорту й відновлення даних.
8. API-ключ через environment незручний для запуску через Finder; початкове ім’я моделі не було підтверджено для публічного API.
9. Не було конфігурації збірки, автоматичних тестів і інструкцій запуску.

## Результат розвитку

`Sources/MyProgressCore` містить моделі, валідоване JSON-сховище, міграцію, статистику та незалежний від AppKit recorder. `Sources/MyProgress` містить SwiftUI/AppKit-інтеграцію. Один `ActivityTracker` створюється на рівні App і поширюється через environment, разом зі спільним `JournalStore`.

Дані: `ProgressDocument` початкової версії 1 (оновлено до версії 2 у розширенні нижче); сесії з UUID, категорією, початком/кінцем, джерелом, задачею й нотаткою; задачі з категорією, терміном і датою завершення; денні цілі; записи щоденника; попередні недатовані підсумки; незворотні відкриття досягнень; явні правила автотрекінгу.

Файл записується атомарно в Application Support. Пошкоджений або невідомий формат не перезаписується; інтерфейс блокує зміни й показує помилку. Резервне відновлення перевіряє формат і зберігає попередню версію окремим файлом. `UserDefaults` лишається джерелом одноразової міграції та локальною чернеткою нотатки.

Статистика розподіляє сесії через північ та враховує календарні межі дня, зокрема літній час. Серія: щонайменше хвилина активності за день; поточний незавершений день не обриває вчорашню серію. Історія за днями не вигадується для старих сумарних значень.

Автотрекінг вимкнений за замовчуванням. AppKit надає bundle identifier активної програми; CoreGraphics — лише тривалість бездіяльності. Правила точні за bundle ID. Ручний режим має пріоритет; бездіяльність, сон і довгі розриви спостережень не накопичуються як робота. Після завершення процесу старий таймер не відновлюється до поточного часу. Спорт і навчання без активної програми вводяться вручну. Немає доступу до вмісту екрана, кейлогінгу або автоматичного читання браузерної історії.

## Межі поточної версії

- macOS UI, Keychain, AppKit і встановлення bundle потребують виконання на Mac; Linux перевіряє ядро й синтаксис, не runtime GUI.
- Облік фокусу програми є оцінкою: активний IDE не гарантує програмування; браузерне правило не розрізняє вкладки. Поріг бездіяльності допускає час до його досягнення.
- Немає Apple Health, iCloud sync, календарної інтеграції, фонового login item, menu bar agent або сторонніх сервісів навчання.
- Одне спільне сховище для вікон у межах процесу. Одночасний запуск двох окремих процесів з одним файлом не підтримується.
- Чернетка зберігається локально в `UserDefaults`, але не входить до JSON-експорту.
- Локальна збірка має ad-hoc підпис; Developer ID, notarization та App Store-дистрибуція не налаштовані.
- API-запити не виконувалися: немає наданих облікових даних; основні функції працюють без AI.

## Наступне розширення: результати, Git та навчання

Додано `OutcomeRecord`, `OutcomeGoal`, `OutcomeStatistics`, read-only `GitReader`, ідемпотентне об’єднання подій, перевірку CSV та звітів ChatGPT. Дані оновлюються до схеми 2 зі збереженням початкових полів і попередньою байтовою резервною копією документа схеми 1.

Спільний `ActivityTracker` залишився власником даних і таймера. Git-читання виконується поза головним актором; запис результатів — на головному. За повторними SHA та зовнішніми id події не дублюються. Задачі закриваються лише за opt-in правилом, явною closing-позначкою й новим комітом відповідного автора, не старшим за саму задачу. Коміти обробляються за датою; повторна перевірка не закриває вручну перевідкриту задачу.

Автотрекінг може мати окреме правило без пауз за клавіатурною бездіяльністю для плеєра. Сон і розриви спостережень залишаються паузами. Це облік фокусу, без інтеграції з фактом відтворення. Жодного читання розмов ChatGPT немає: користувач сам вставляє структурований підсумок та підтверджує кількості. Фільми, слова, уроки й вправи — окремі метрики без вигаданого сумарного рейтингу.

UI розширено через спільні компоненти `AppCanvas`, `Panel`, `PageHeading`, `StatCard` та `OutcomeGoalCard`. Стара навігація й екрани збережені, додано результати, вибір теми, кільця цілей, menu bar та необов’язковий `SMAppService`-автозапуск. Необхідні перевірки нової UI/OS-інтеграції на Mac перелічено в README.
